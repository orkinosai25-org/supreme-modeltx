# T‑301 Retrieval & Benchmark Module

## Overview

T‑301 provides RAG‑style retrieval and benchmark dataset management for the SMTX pipeline.

## Features

- Dense embedding store (FAISS backend)
- RAG top‑k retrieval (default k=5)
- Benchmark dataset runner: MMLU, HellaSwag, ARC‑Challenge
