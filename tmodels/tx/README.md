# T‑X Orchestrator

## Overview

T‑X is the governance and judgment layer of SMTX. It routes queries to the appropriate T‑Series modules, collects candidate responses, scores confidence, and selects the best answer.

## Features

- Confidence‑weighted routing across T‑101, T‑201, T‑301, T‑501
- Highest‑confidence judgment mode
- Audit logging of all routing decisions
- Configurable confidence threshold (default 0.75)
