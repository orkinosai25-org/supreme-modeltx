# T‑201 Reasoning Module

## Overview

T‑201 is a reasoning‑specialist fine‑tuned model built on top of T‑101.
It handles chain‑of‑thought (CoT) tasks, logic puzzles, and multi‑step reasoning.

## Fine‑Tuning

- Method: ORPO / DPO alignment
- Dataset: Synthetic CoT reasoning pairs
- Benchmarks: GSM8K, ARC, MATH
