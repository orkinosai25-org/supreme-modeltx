# Source grounding and claim boundaries

Official documentation below describes potential technologies, not integrations
in this repository. NeMo, Megatron Core, TensorRT-LLM, and ONNX are planned, not
integrated. CUDA paths exist but are not GPU-validated; cuDNN is a runtime library.
