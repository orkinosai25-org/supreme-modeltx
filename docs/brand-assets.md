# SMTX Brand Assets

## Logo

The primary SMTX logo is the **chrome T‑X emblem** located at `branding/modeltx_logo.svg`.

### Usage Guidelines

- Use the chrome variant on dark backgrounds
- Use the monochrome variant on light backgrounds
- Minimum size: 32×32 px
- Do not distort or recolor without approval

## Color Palette

| Name | Hex |
|------|-----|
| Chrome Silver | `#C0C0C0` |
| Deep Space Black | `#0A0A0A` |
| Sovereign Blue | `#1A3AFF` |
| Inference Gold | `#FFD700` |

## Typography

- Headings: **Inter** (Bold)
- Body: **Inter** (Regular)
- Code: **JetBrains Mono**
